Strategy guide

Arrow Puzzle Help

Your goal is to make every tile point upward. In number mode, the solved state is when every tile shows 1. Each tap rotates the selected tile and its neighboring tiles, so the best strategy is to solve the board in controlled rows instead of tapping randomly.

Core rule

How a move works

Tap = rotate +1

A tile does not rotate alone. When you tap one tile, that tile and the cells around it rotate one clockwise step. This is why solving requires planning: every correction also changes nearby tiles.

Square boards

Easy and Medium use square boards. The selected tile and all surrounding cells are affected, including diagonal corners.

Hex boards

Hard and Expert use a hexagonal board. Each tap affects the selected tile and the six neighboring cells around it.

Recommended flow

General solving idea

1 Start at the top

Solve the upper row first so it becomes a stable reference.

2 Use the row below

Tap tiles below the row you want to correct.

3 Control the bottom

The final row cannot be solved the same way, so it must be encoded or matched.

4 Finish from the top

Use the top rows to complete the last correction pattern.

Algorithms

Step-by-step solving methods

Easy Square board basics

The Easy strategy is based on solving a row, using the row below it to clean up the remaining tiles.

  1. Solve the top row, then solve the middle row by tapping tiles below the row.
  2. Make the center tile of a row the same as one edge tile.
  3. Make the row all the same number.
  4. Solve the row.
  5. Solve the bottom row the same way, but use the middle row to control it.
  6. Using the top row, finish the solve.
Medium Larger square board

The Medium strategy follows the same row logic, but it requires more control because there are more tiles in each row.

  1. Solve the top three rows one after another, tapping tiles below the row.
  2. Make the center tile the same as its adjacent edge tile.
  3. Make the other center tile the same as its adjacent edge tile.
  4. Solve the left two tiles by pressing.
  5. Solve the right two tiles by pressing.
  6. Solve the bottom row the same way, but by using the bottom row itself.
  7. Using the first and second row, finish the solve.
Tip: When you solve during step 2, tap the first row the same number of times as the bottom row. You can then use row 2 to finish the solve.
Propagation For Hard and Expert

Propagation means pushing corrections across the board in a controlled direction until the row becomes filled with 1s. This is the key technique for Hard and Expert boards.

  1. Solve the top row by tapping tiles directly below the row.
  2. Solve the center tile.
  3. Solve the tile to the left of the center tile.
  4. Solve the tile two spaces to the left of the center tile.
  5. Solve the tile three spaces to the left of the center tile.
  6. Repeat the same process to the right of the center tile.
  7. The top row should now be entirely filled with 1s.
  8. Repeat step 1 for every row until the bottom row, but do not solve the bottom row yet.

To verify there is no mistake

  • When you are done, your board will be symmetric.
  • The two tiles adjacent to the bottom center tile will always be 1 or 4.
Hard and Expert Final encoding method

Before using this method, read and practice propagation. Hard and Expert require you to encode the bottom row into the top row, then propagate again to finish.

  1. Propagate.
  2. Label the bottom right cells from left to right: A, B, C, D. Label the top right cells from left to right: a, b, c, d. You will tap the top row to encode the bottom row onto it.
  3. Tap a so that a is the same as C.
  4. Tap b and d the number of times you will need to solve C.
  5. Tap a the number of times you would need to solve D.
  6. If B + D is odd, tap c three times in Expert or once in Hard. Otherwise, skip this step.
  7. Propagate from the top once more to finish the solve.
