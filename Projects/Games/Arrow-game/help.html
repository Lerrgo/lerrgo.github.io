Arrow Puzzle Help

Make every tile point upward. In number mode, solve the board by making every tile show 1.

Move rule

Tap a tile to rotate that tile and the surrounding tiles by one clockwise step.

Square boards

Easy and Normal use square boards. The selected tile and all surrounding cells are affected, including diagonal corners.

Hex boards

Hard and Expert use a hexagonal board. Each tap affects the selected tile and the six neighboring cells around it.

Difficulty guide

Easy

Small square board. Good for learning the rotation pattern.

Normal

Larger square board. Work gradually from one area to another.

Hard

Hexagonal board with four possible arrow states.

Expert

Hexagonal board with six possible arrow states.

Solving approach

  1. Focus on one region. Avoid tapping randomly across the whole board.
  2. Use number mode when needed. Number mode makes the states easier to track. The solved state is 1.
  3. Watch the edges. Edge tiles affect fewer neighbors, so they are useful for smaller corrections.
  4. For hex boards, think in rings. Correct the outer ring first, then move inward.
